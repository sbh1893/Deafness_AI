# AI 학습 파이프라인 설계 — 오디오 기반 혀 위치 시각 피드백 (영어 발음 학습 앱)

> 방향 전환 검토: sEMG 센서 없이, 오디오(마이크)만으로 혀 위치를 추정해
> 시각 피드백을 주는 방식. 대상은 "한국인 대상 영어 발음 학습"으로 재검토 중.
> TaL Corpus(오디오+초음파 혀 영상 페어 데이터)를 활용하는 것을 전제로 설계함.

---

## 0. 전제와 원칙

1. **목표는 "정확한 3D 좌표 복원"이 아니라 "대략적인 방향성 피드백"이다.**
   음향-조음 역변환(acoustic-to-articulatory inversion)은 다대일 매핑 문제라
   원리적으로 완벽한 정답이 없다. 그래서 처음부터 정밀 좌표가 아닌
   **저차원 조음 파라미터(예: 혀의 전후/고저 위치 2~3개 축)** 를
   예측 목표로 잡는다. (이전에 설계한 "실선=정밀, 점선=개략적" 원칙과 동일한 철학)
2. **화자독립(speaker-independent) 평가를 기본으로 한다.**
   실제 사용자는 TaL 학습 데이터에 없는 새로운 한국인 화자이므로,
   TaL 화자들로 학습하고 처음 보는 화자에게도 통하는지가 핵심 검증 기준이다.
3. **초음파 장비는 학습 단계에만 쓰고, 배포 단계(실사용)에서는 마이크만 쓴다.**
   (Zheng, Ai & Ling 2023의 지식증류 발상과 동일한 "교사-학생" 구도이나,
   본 파이프라인은 그보다 단순한 지도학습 회귀 문제로 설계한다.)

---

## 1. 데이터 준비 단계

### 1-1. 데이터 소스
- **TaL80** (81명 화자, 오디오+초음파+입술영상 동기화, 약 22시간)
  → 화자 수가 많아 화자독립 학습에 적합. 주력 학습 데이터.
- **TaL1** (전문 성우 1명, 6세션)
  → 세션 간 재현성 검증용 보조 데이터로 활용.

### 1-2. 전처리
| 단계 | 내용 |
|---|---|
| 오디오 특징 추출 | Mel-spectrogram 또는 MFCC (13~40차원), 프레임 이동 10ms 권장 |
| 초음파 라벨 단순화 | 원본 64×842 초음파 프레임을 그대로 예측하지 않고, **혀 윤곽선 추출 → 저차원 파라미터로 축소** (예: eigentongue 분해 — TaL 논문이 인용한 Fabre 외의 방식, 또는 PCA로 상위 2~5개 성분만 사용) |
| 시간 정렬 | 오디오 프레임과 초음파 프레임의 샘플링 레이트가 다르므로(오디오 100fps 특징 vs 초음파 ~80fps), 선형보간으로 시간축 맞춤 |
| 화자 분할 | 화자 단위로 train/val/test 분리 (예: 65명 학습 / 8명 검증 / 8명 테스트) — **프레임 단위로 섞으면 안 됨** (세션 독립적 검증 원칙과 동일한 이유) |
| 정규화 | 화자별 평균/분산으로 오디오 특징 정규화 (화자 간 목소리 톤 차이 보정) |

### 1-3. 라벨 단순화가 중요한 이유
초음파 원본 이미지를 그대로 예측 목표로 삼으면:
- 모델이 지나치게 복잡해지고, 실시간 추론에 부담
- "정확한 이미지"를 보여주는 건 화면 설계 원칙(정직한 정밀도)과도 안 맞음

대신 "혀가 앞/뒤로 얼마나 나와 있는가", "혀가 위/아래로 얼마나 올라가 있는가" 같은
**2~3차원 요약 지표**로 축소하면, 화면에도 자연스럽게 화살표·게이지로 표시 가능하고
모델도 훨씬 가볍고 안정적으로 학습된다.

## 2. 모델 구조

```
[마이크 입력]
     │
     ▼
[오디오 특징 추출] Mel-spectrogram / MFCC
     │
     ▼
[오디오 인코더] 1D CNN 또는 소형 Transformer (TaL 논문의 3D-CNN+BLSTM 구조보다 경량화)
     │
     ▼
[조음 파라미터 디코더] Fully-Connected layers
     │
     ▼
[출력] 혀 전후 위치(1차원), 혀 고저 위치(1차원) — 총 2차원 회귀값
```

- **1단계(빠른 검증용, 추천 시작점)**: eigentongue 계수 + 고전적 회귀(선형회귀 또는 얕은 MLP)로 베이스라인을 먼저 만든다. TaL 논문이 인용한 Fabre 외(2015)의 "eigentongue decomposition + 인공신경망" 방식이 정확히 이 수준이다. 복잡한 딥러닝 전에 이 베이스라인으로 "오디오만으로 혀 위치를 얼마나 맞힐 수 있는지" 감을 먼저 잡는다.
- **2단계(성능이 필요하면)**: CNN/Transformer 기반 인코더로 고도화.

## 3. 학습 전략

| 항목 | 설정(권장 시작값) |
|---|---|
| 손실 함수 | MSE (평균제곱오차) — 조음 파라미터 회귀 |
| 검증 지표 | 화자독립 테스트셋에서의 **피어슨 상관계수(r)** — TaL 논문도 화자별 결과를 상관계수로 비교했음 |
| 데이터 증강 | 오디오 피치 변형, 노이즈 추가 (한국인 화자의 음향 특성이 TaL의 영어 원어민과 다를 수 있으므로, 강건성 확보 목적) |
| 과적합 방지 | 화자 단위 K-fold 교차검증 (03_semg에서 세션 단위로 나눴던 것과 동일한 원칙 — 화자 단위로 나눔) |

## 4. 평가 단계

1. **화자독립 정확도**: TaL 테스트 화자(학습에 없던 8명)에서 예측값과 실제 초음파 기반 조음 파라미터 간 상관계수 확인
2. **음소별 분석**: 목표로 하는 영어 발음(R/L, TH 등 한국인이 어려워하는 음소)에서 특히 정확도가 어떤지 별도 확인 — 전체 평균이 좋아도 정작 필요한 음소에서 나쁘면 의미 없음
3. **정성적 확인**: 실제로 화면에 그려봤을 때 "말이 되는 방향"으로 움직이는지 육안 확인 (예: R 발음 시 혀가 뒤로 가는 게 화면에도 반영되는지)

## 5. 배포(실사용) 파이프라인

```
[사용자 마이크 입력] (실시간, 웹캠은 입모양 별도 처리 - 01_webcam_vsr 재사용)
     │
     ▼
[오디오 특징 추출] (학습 때와 동일한 전처리)
     │
     ▼
[학습된 오디오→조음 파라미터 모델] (2단계 CNN/Transformer, 경량화된 추론용 버전)
     │
     ▼
[혀 위치 화면 표시] 이전에 설계한 "정적 참조 단면도 + 점선 현재 위치 마커" 방식 그대로 재사용
     │
     ▼
[텍스트 힌트] "혀를 조금 더 뒤로 이동해보세요" 등
```

**핵심**: 03_semg에서 sEMG로 하려던 역할을, 이 파이프라인에서는 마이크(오디오)가 대신한다.
새 하드웨어(센서) 없이 웹캠+마이크만으로 시스템이 완결된다는 게 최대 장점이다.

## 6. 폴더 구조 제안 (구현 시)

```
Deafness_AI/  (또는 새 프로젝트명으로 분리 검토)
└── 04_audio_to_tongue/
    ├── 01_prepare_data.py       <- TaL 데이터 다운로드 후 특징 추출·정렬
    ├── 02_baseline_eigentongue.py  <- 1단계 베이스라인 (eigentongue + 선형회귀)
    ├── 03_train_model.py        <- 2단계 CNN/Transformer 학습
    ├── 04_evaluate.py           <- 화자독립 평가, 상관계수 계산
    └── 05_realtime_inference.py <- 실사용 데모 (마이크 입력 → 화면 표시)
```

## 7. 이번 방향 전환과 관련해 다시 강조할 점

- 이 파이프라인은 **영어(TaL) 데이터로 방법론 자체를 검증**하는 것이 1차 목표다.
- "한국인 영어 학습자용으로 실제 서비스화"할지, 원래 목표인 "청각장애인 자가 조음훈련"으로
  되돌아갈지는 **아직 결정된 사안이 아니며, 소장님/대표님과 상의가 필요하다**는 점을
  이전 대화에서 안내한 그대로 유지한다.
- 다만 이 오디오→혀위치 모델 자체는 **두 시나리오 모두에 재사용 가능**하다는 점이
  중요하다 — 청각장애인 대상으로 회귀하더라도, sEMG 없이 마이크만으로 혀 위치
  피드백을 줄 수 있다면 하드웨어 요구사항이 크게 줄어드는 공통 이득이 있다.
