# AI Hub 한국어 데이터셋 후보 정리

> 청각장애인 자가 조음 훈련 시스템 프로젝트에 활용 가능한 AI Hub 데이터셋을 관련성 순으로 정리한 문서입니다.

---

## 1순위 — 핵심 데이터셋

### 립리딩(입모양) 음성인식 데이터
- **dataSetSn**: 538
- **링크**: https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&dataSetSn=538
- **내용**: 소음 환경에서 음성인식을 보완하는 입모양 인식용 오디오·비주얼 융합 데이터
- **관련성**: ★★★ — 데이터셋 소개 페이지에서 **청각장애인 발음 교정 서비스 개발 활용**을 명시적으로 언급하고 있는, 국내에서 가장 직접적으로 관련된 데이터셋
- **활용처**: 01_webcam_vsr의 VSR 모델을 정식으로 고도화할 때 학습 데이터로 사용

### 구음장애 음성 데이터
- **dataSetSn**: 608
- **링크**: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=608
- **내용**: 한림대 강남성심병원·동탄성심병원 등에서 구음장애 환자 1,200명 이상으로부터 확보한 5,000~5,250시간 분량의 원시 발화 데이터
- **관련성**: ★★★ — 장애 유형별 비정상 발화 패턴이 딥러닝 모델로 각각 구현되어 있어, 국내 최대 규모의 비정형 발화 데이터셋
- **주의**: 청각장애 자체보다는 구음장애(조음/운동성 발화장애) 데이터라는 점 구분 필요. 보건의료 데이터 특성상 **온라인/오프라인 안심존**을 통해서만 열람 가능할 수 있음 — 신청 전 확인 필요.
- **활용처**: "장애로 인한 비정형 발화가 정상 발화와 음향학적으로 어떻게 다른가"를 학습하는 참고 자료, 03_semg/02_mic_acoustic 특징 설계에 참고

---

## 2순위 — 보조적으로 유용한 데이터셋

### 한국어 아동 음성 데이터
- **dataSetSn**: 540
- **링크**: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=540
- **내용**: 아동의 낭독 발화 음성을 수집한 데이터. "아이의 부정확한 발음에도 잘 인식되도록" 아동 음성 인식 개선을 목적으로 구축됨
- **관련성**: ★★☆ — 조음장애가 아닌 "일반 아동의 미숙한 발음"을 반영한 데이터라는 점에서 청각장애 관련 데이터와는 성격이 다름. 다만 목표 음소(비음, 연구개음)가 일반 아동 발화에서 어떻게 나타나는지 비교 기준선으로 참고 가능
- **활용처**: 목표 음소의 정상 발달 패턴 참고 (대조군 데이터로 활용 가능)

### 학습용 아동 영어 음성 데이터
- **dataSetSn**: 541
- **링크**: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=541
- **관련성**: ★☆☆ — 영어 데이터라 직접 활용도는 낮으나, 위 한국어 아동 데이터와 동일한 구축 기관·방법론으로 만들어져 있어 데이터 구조를 참고할 때 함께 볼 수 있음

### 외국어 발음 교육 및 평가 데이터
- **dataSetSn**: 71463
- **링크**: https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&dataSetSn=71463
- **내용**: 한국인의 외국어 발화 음성 및 학습자별 수준 분류·평가, 언어학적 분석 메타데이터
- **관련성**: ★★☆ — 목표 사용자층은 다르지만, **"발음 정확도를 어떻게 등급화·평가하는가"라는 방법론**(학습자 수준 분류, 언어학적 분석 메타데이터 구조)이 6~8장의 판정 기준 설계에 참고할 만함

### 감정 분류를 위한 대화 음성 데이터셋
- **dataSetSn**: 263, 637
- **관련성**: ★☆☆ — 직접적 관련성은 낮음. 추후 "사용자의 좌절감·성취감을 반영한 UX"를 고민할 때 참고 가능한 수준

## 참고사항
- AI Hub 데이터 대부분은 다운로드 전 **승인 절차**가 필요합니다.
- 보건의료 관련 데이터(구음장애 음성 데이터 등)는 **온라인/오프라인 안심존**을 통해서만 열람 가능할 수 있으니, 신청 전 데이터셋 상세 페이지에서 이용 절차를 반드시 확인하세요.
