# 영어 데이터셋(TaL 초음파 + Gaddy sEMG) 결합 실험 검토 노트

> "혀 초음파 데이터(TaL)와 sEMG 영어화자 1명 데이터(Gaddy)를 같이 학습시키면 영어로 테스트 가능할까?"라는 질문에 대한 검토 내용을 정리한 문서입니다.

---

## 결론 요약

**단순히 두 데이터셋을 합쳐서 학습시키는 것은 불가능합니다.** 다만 "오디오"를 매개로 간접 연결하는 실험적 방법은 시도해볼 수 있습니다.

---

## 왜 단순 결합이 안 되는가

- TaL(초음파+입술영상+오디오)과 Gaddy(sEMG+오디오)는 **서로 다른 사람, 다른 세션**에서 독립적으로 수집된 데이터입니다.
- 같은 사람이 초음파와 sEMG를 동시에 착용하고 녹음한 게 아니므로, "이 순간의 혀 모양"과 "이 순간의 근전도 신호"를 짝지어줄 근거(paired data)가 원천적으로 없습니다.
- 관계없는 두 데이터를 억지로 같은 모델에 넣으면, 모델은 실제로는 존재하지 않는 상관관계를 학습하게 됩니다(허위 패턴 학습).

## 그래도 가능한 방법 — 오디오를 다리로 쓰는 간접 연결

두 데이터셋에 **공통으로 존재하는 유일한 모달리티가 오디오**라는 점을 이용합니다.

### 절차
1. **1단계**: TaL 데이터로 "오디오 → 혀 모양(초음파)" 매핑 모델을 학습한다.
   (참고: `raw/thesis/08_초음파_지식증류_음성향상.md`에서 다룬 Zheng 외(2023)의 지식증류 구조와 유사한 발상)
2. **2단계**: 1단계 모델에 Gaddy 데이터셋의 오디오(발성 발화에 딸린 오디오)를 입력하여, Gaddy 화자의 **추정 혀 모양(가짜 라벨, pseudo-label)**을 생성한다.
3. **3단계**: 이렇게 만든 추정 혀 모양과 실제 Gaddy sEMG 신호를 시간 축으로 짝지어, "EMG → 혀 모양" 관계를 학습한다.

### 이 방법의 의의
초음파 장비 없이 EMG만으로 혀 상태를 추정하는 모델의 얼개를, 별도의 실측 페어링 데이터 없이도 구성해볼 수 있는 실험적 파이프라인입니다.

## 한계 및 주의사항

- **검증된 방법이 아닙니다.** 문헌 조사에서 TaL과 Gaddy를 이렇게 결합한 선행 연구는 발견되지 않았습니다 — 시도한다면 새로운 조합입니다.
- **화자 불일치 문제**: TaL 화자들의 억양·발화 습관으로 학습한 오디오→혀모양 매핑이, Gaddy의 단일 화자에게 얼마나 잘 일반화될지는 불확실합니다.
- **가짜 라벨의 품질이 하한선을 결정합니다.** 1단계 모델이 부정확하면 이후 모든 단계가 그 오차를 그대로 물려받습니다.
- 두 데이터셋 모두 **화자가 극히 제한적**(TaL80은 다화자지만 Gaddy는 단일 화자)이라, 일반화 가능성 자체에 한계가 있습니다.

## 더 현실적인 대안 (권장)

두 데이터셋을 억지로 결합하기보다, **따로따로 검증하는 것을 권장합니다.**

1. **Gaddy 데이터셋만으로** `03_semg` 코드의 필터링·정규화·분류 파이프라인이 실제로 잘 작동하는지 검증 (센서 도착 전 코드 디버깅 목적)
2. **TaL 데이터셋만으로** Zheng 외(2023)의 지식증류 구조를 재현해서, "초음파 정보가 실제로 도움이 되는가"라는 아이디어 자체를 영어로 먼저 확인

### 이 방식이 나은 이유
- 최종 목표가 한국어 음소(비음 ㅁㄴㅇ, 연구개음 ㄱㅋㄲ)이므로, 영어 데이터 실험은 애초에 "코드/방법론이 말이 되는지"를 미리 검증하는 용도입니다.
- 억지로 결합한 파이프라인의 불확실성을 늘리는 것보다, 각 데이터셋의 원래 목적(TaL=조음-음향 매핑, Gaddy=EMG-음성 변환)에 맞게 검증하는 것이 결과 해석이 훨씬 명확합니다.
